## 产品事实

- 项目面向 Foundry VTT 14、Call of Cthulhu 7e ≥ 8.16；当前参考版本 0.9.1。
- 本次只参考 investigator / character 的信息架构，不采用其深色漆面、黄铜、盾形 SVG 或实现代码。
- 布局骨架：顶部横幅 → 七页签 → 主区；主区左侧为可收起收藏栏。
- 横幅顺序：头像、姓名与锁定控制；职业/年龄/性别/居住地/玩家；HP/MP/SAN/幸运；DB/体格/MOV/护甲（以及参考项目的灵感/知识）；STR/CON/SIZ/DEX/APP/INT/POW/EDU 八特性及半值、1/5 值；七种状态与今日 SAN。
- 七页签固定顺序：技能、简表、物品、背景、成长、笔记（GM）、效果。

## 页内信息顺序

1. 技能：搜索、数值/名称排序、罕见技能、添加；技能表（名称/基础/当前/半值/1/5/成长/操作），专长分组。
2. 简表：武器速查（名称/技能%/伤害/射程/每轮/子弹·弹容量/故障/攻击/伤害/装填）；之后为战斗、调查、社交、生存、技艺、医疗与精神技能芯片。
3. 物品：信用评级/现金/资产/消费水平；武器、护甲、书籍、法术、天赋、道具、状态分节。
4. 背景：职业/年龄/性别/出生地/居住地/组织；七要素（外貌形象、思想信念、宝贵之物、意义非凡之地、重要之人、特质、伤疤和恐惧症），关键链接多选；背景故事；遭遇记录。
5. 成长：兴趣/职业/原型/经验包点数；可以成长的技能与一键成长、手动调整；按模组分组成长记录、撤销、新建模组。
6. 笔记：守秘笔记；书籍研究；SAN 损失事件；神话标记与状态清除；货币配置。
7. 效果：效果列表、启用/禁用、打开配置、删除、新增。

## NPC / 生物卡补充事实

来源新增：同仓库 `docs/04-生物卡设计文档.md`、`prototype/npc.html`、`docs/screenshots/npc-*.png`。

- 作用域为 `npc` + `creature`，布局沿用顶部横幅，但**没有收藏侧栏**。
- 身份：npc 显示职业/年龄/组织，creature 显示类型。
- 资源：HP/MP/SAN/幸运，空值在锁定态隐藏；派生为 DB/体格/MOV/护甲；八特性缺值显示 `—`。
- 横幅底行：七种状态 + 每轮攻击 + SAN 损失 + 护甲；不是角色卡的今日 SAN。
- 六页签固定顺序：**战斗（默认）/ 技能 / 物品 / 描述 / 守秘（GM）/ 效果**。
- 战斗页：每轮攻击/SAN 损失/护甲速览；武器表（名称/使用技能/备选技能/伤害/射程/子弹·弹容量/故障/操作）；特殊能力；主移动与额外移动方式。
- 技能页：名称/当前/半值/1/5，搜索与数值/名称/自定义排序；没有基础、成长、职业/兴趣或罕见技能列。
- 物品页：护甲/书籍/法术/天赋/道具/状态；武器只在战斗页；没有货币条。
- 描述页：类型或职业/年龄/组织 + `personalDescription`；没有背景七要素、关键链接或遭遇。
- 守秘页：守秘笔记、骰子宏、状态清除；没有书籍进度、SAN 事件或神话标记。
- 编辑态含公式模式、批量掷特性/取平均、auto 开关；缺值资源可在编辑态补录。

## 载具卡事实与边界

- 参考项目明确不做 `vehicle`，不存在可照搬的“参考版载具卡”。
- 本系统 `template.json:204-232` 与 `module/actor/sheets/coc/vehicle-view-data.mjs` 的现行字段为：
  `stats.hp`、`stats.build`、`stats.mov`、`stats.armor`、`crew.total`、`description.value/keeper`、`infos.type/origin`、`properties.armed`。
- 当前视图没有人物八特性、攻击、技能、装备、状态或效果数据；设计稿不得虚构这些区块。
- 因数据量较小，采用单页载具摘要：类型/来源与武装标记 → 耐久 → 体格/移动/护甲 → 乘员与机组 → 描述 → 守秘笔记。

## 本次设计边界

- 角色卡与 NPC 的排列分别沿用以上参考顺序；载具按本系统原生字段组织。
- 视觉只使用本项目纸墨 UI，交付独立高保真 HTML，不修改生产模板、样式或数据。
- 示例数据仅用于设计评审；没有后端掷骰、保存或权限能力。
